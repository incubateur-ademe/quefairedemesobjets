# Open Data

Cette section de documentation est exceptionnellement écrite en Français pour des raisons pratiques. Cette documentation est utilisée pour la publication des données sur de plateforme francophone.

«Que faire de mes objets et déchets» publie les données consolidées des acteurs de l'économie circulaire, ainsi que ses fiches objets et déchets et leurs consignes, sur les plateformes data.gouv.fr et data.ademe.fr
