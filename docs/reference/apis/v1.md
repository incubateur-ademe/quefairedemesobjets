# Public API v1

## Principle

`/api/v1/` exposes what the sorting, reuse and repair assistant can do, with
the same parameters: the assistant is the first client of its own API. The
map, the search fields and the lieu pages call these endpoints, so there is no
second code path to maintain.

A single selection chain, `DisplayedActeurQuerySet` (`proposing`,
`nearest_to`, `within`), serves the screens and the API with the same
parameters (`webapp/qfdmo/lieux_query.py`). Two routers are mounted on `/api/v1/`:

- `webapp/opendata/api.py`: the open data of lieux, gestes, objets and
  déchets, a public contract for reusers;
- `webapp/assistant/api.py`: the suggestions of the assistant's search fields.

The `NinjaAPI` instances live in `webapp/core/api.py`.

## Scope: the open dataset

`/lieux` and `/lieux/{identifiant}` return the lieux of the
[Acteurs de l'économie circulaire](https://data.ademe.fr/datasets/longue-vie-aux-objets-acteurs-de-leconomie-circulaire)
dataset published on data.ademe.fr: active acteurs with at least one source
under an open licence (`open_data()`, `webapp/opendata/lieux.py`). Columns
carry the same names as the CSV, to go from one to the other without a mapping
table.

Known, accepted differences with the CSV:

- columns computed by data.ademe.fr after the export (`nom_region`,
  `nom_departement`, `_siret_infos…`) are not served;
- neither are the per-action columns (`reparer`, `donner`…):
  `propositions_de_services` carries the same information;
- `identifiants_des_contributeurs` is not served;
- `paternite` is a list of objects (`code`, `nom`, `url`, `logo`) where the
  CSV joins the names with `|`; the site and ADEME come first, without a
  `code`, then the open licence sources by name:
  `[{"code": null, "nom": "ADEME", "url": "https://www.ademe.fr", "logo": null}, …]`;
- acteurs working only at home (`lieu_prestation = A_DOMICILE`) are missing
  from the map's table, hence from the API;
- the masking of phone numbers in the CSV (mobiles, Carteco source) is applied
  in the data-platform, not here.

## Endpoints

| Endpoint                   | Purpose                                              |
| -------------------------- | ---------------------------------------------------- |
| `GET /lieux`               | open licence lieux, paginated (`limit`, `offset`)    |
| `GET /lieux/{identifiant}` | one lieu, by its public identifier (`uuid`)          |
| `GET /gestes`              | the gestes: values of the `geste` parameter, colours |
| `GET /objets?q=`           | objet suggestions, `slug` = value of `fiche`         |
| `GET /adresses?q=`         | address suggestions (BAN), `precise` address/town    |
| `GET /produits`            | objets and déchets                                   |
| `GET /consignes`           | consignes of each objet or déchet                    |

`/produits` and `/consignes` answer paginated JSON (`limit`, `offset`) by
default, and return the whole table as CSV with the `Accept: text/csv` header:
`limit` and `offset` do not apply to the CSV. Responses carry `Vary: Accept`.
The other endpoints only serve JSON.

```bash
curl -H "Accept: text/csv" https://quefairedemesdechets.ademe.fr/api/v1/consignes
```

Interactive documentation: `/api/v1/docs`.

`/produits` and `/consignes` are the two tables of the
[objets et déchets fiches](../opendata/exposure-opendata-fiches.md) dataset:
same columns as the CSV files, which the export DAG downloads here
(`webapp/opendata/api.py`).

## Lieux parameters

The vocabulary is the one of the screens' URLs (`assistant/parcours.py`): a
screen's query string can be passed as is.

| Parameter               | Required          | Value                                             |
| ----------------------- | ----------------- | ------------------------------------------------- |
| `geste`                 | ✅ repeatable     | code of a `GroupeAction`, see `/gestes`           |
| `fiche`                 | ⚪️                | slug of an objet fiche; unknown: `404`            |
| `longitude`, `latitude` | ✅ without `bbox` | search point, sorted by distance                  |
| `bbox`                  | ✅ without point  | visible area (Leaflet shape), wins over the point |

Invalid input returns `422` (django-ninja's convention), never a silent
fallback: an unreadable bbox is not replaced by the point.
