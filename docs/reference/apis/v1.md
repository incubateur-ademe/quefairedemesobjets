# API publique v1

## Principe

`/api/v1/` expose ce que l'assistant au tri, au réemploi et à la réparation
sait faire, avec les mêmes paramètres : l'assistant est le premier client de
son API. La carte, les champs de recherche et les pages de lieu appellent ces
endpoints, il n'y a donc pas de second chemin de code à maintenir au niveau.

Le routeur `webapp/opendata/api.py` y sert l'open data (fiches), contrat public
pour les réutilisateurs.

Les instances `NinjaAPI` sont dans `webapp/core/api.py`.

## Endpoints

| Endpoint         | Rôle                                                        |
| ---------------- | ----------------------------------------------------------- |
| `GET /produits`  | fiches objets et déchets, paginées ; `.csv` pour le fichier |
| `GET /consignes` | consignes des fiches, paginées ; `.csv` pour le fichier     |

Documentation interactive : `/api/v1/docs`.

`/produits` et `/consignes` sont les deux tables du jeu de données
[fiches objets et déchets](../opendata/exposure-opendata-fiches.md) : mêmes
colonnes que les CSV, que le DAG d'export télécharge ici (`webapp/opendata/api.py`).
