# API publique v1

## Principe

`/api/v1/` expose ce que l'assistant au tri, au réemploi et à la réparation
sait faire, avec les mêmes paramètres : l'assistant est le premier client de
son API. La carte, les champs de recherche et les pages de lieu appellent ces
endpoints, il n'y a donc pas de second chemin de code à maintenir au niveau.

Une seule chaîne de sélection, `DisplayedActeurQuerySet` (`proposing`,
`nearest_to`, `within`, `for_the_map`, `open_data`), sert les écrans et l'API.
Le code est dans `webapp/assistant/api.py`, les instances `NinjaAPI` dans
`webapp/core/api.py`.

## Périmètre : le jeu de données ouvert

`/lieux` et `/lieux/{identifiant}` renvoient les lieux du jeu de données
[Acteurs de l'économie circulaire](https://data.ademe.fr/datasets/longue-vie-aux-objets-acteurs-de-leconomie-circulaire)
publié sur data.ademe.fr : les acteurs actifs dont au moins une source est
sous licence ouverte (`open_data()`). Les colonnes portent les mêmes noms que
le CSV, pour passer de l'un à l'autre sans table de correspondance.

Écarts connus avec le CSV, assumés :

- les colonnes calculées par data.ademe.fr après export (`nom_region`,
  `nom_departement`, `_siret_infos…`) ne sont pas servies ;
- les colonnes par action (`reparer`, `donner`…) non plus :
  `propositions_de_services` porte la même information ;
- `identifiants_des_contributeurs` n'est pas servi ;
- les acteurs uniquement à domicile (`lieu_prestation = A_DOMICILE`) sont
  absents de la table de la carte, donc de l'API ;
- le masquage des numéros de téléphone du CSV (mobiles, source Carteco) est
  appliqué côté data-platform, pas ici.

`/lieux.geojson`, lui, sert la carte de l'assistant : toutes sources
confondues, 20 lieux au plus (#3356), propriétés réduites à ce que la punaise
affiche.

## Endpoints

| Endpoint                   | Rôle                                                    |
| -------------------------- | ------------------------------------------------------- |
| `GET /lieux`               | lieux en licence ouverte, paginés (`limit`, `offset`)   |
| `GET /lieux.geojson`       | lieux pour la carte, FeatureCollection, 20 au plus      |
| `GET /lieux/{identifiant}` | un lieu, par son identifiant public (`uuid`)            |
| `GET /gestes`              | les gestes : valeurs du paramètre `geste`, couleurs     |
| `GET /objets?q=`           | suggestions d'objets, `slug` = valeur de `fiche`        |
| `GET /adresses?q=`         | suggestions d'adresses (BAN), `precise` adresse/commune |

Documentation interactive : `/api/v1/docs`.

## Paramètres des lieux

Le vocabulaire est celui des URL des écrans (`assistant/parcours.py`) : une
query string d'écran se transmet telle quelle.

| Paramètre               | Obligatoire      | Valeur                                           |
| ----------------------- | ---------------- | ------------------------------------------------ |
| `geste`                 | ✅ répétable     | code d'un `GroupeAction`, voir `/gestes`         |
| `fiche`                 | ⚪️               | slug d'une fiche objet ; inconnu : `404`         |
| `longitude`, `latitude` | ✅ sans `bbox`   | point de recherche, tri par proximité            |
| `bbox`                  | ✅ sans le point | zone visible (forme Leaflet), prime sur le point |

Une entrée invalide renvoie `422` (convention django-ninja), jamais de repli
silencieux : une bbox illisible n'est pas remplacée par le point.
